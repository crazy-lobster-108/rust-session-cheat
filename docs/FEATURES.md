# Rust Session Tracker — feature reference

A session tracker workspace for Rust, built around session notes and resource records, with activity timeline kept in a separate reference area.

| Section | Description |
|---|---|
| Session notes | Session and activity information grouped by the task or context it belongs to. |
| Resource records | Inventory and resource categories organized alongside their related values and notes. |
| Activity timeline | Session and activity information grouped by the task or context it belongs to. |
